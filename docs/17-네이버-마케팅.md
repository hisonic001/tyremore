## 블로그 초안이 만들어지는 과정 (`src/lib/blog-draft.ts`)

1. **글감 고르기** `pickCandidates` — 그날 성사 판매 중 타이어가 있는 것. 거래처·무상(서비스)·이미 초안 있는 건 제외.
   4본 교체 우선, 같은 차종은 하루 하나.
2. **사실 만들기** `factsText` — 지시문에 들어가는 전부. `--dry` 로 눈으로 확인할 수 있다.
   ```
   차량: 현대 그랜저 2019년식, 주행 8만km대
   시공: 미쉐린 프라이머시4 235/45R18 4본
   시기: 8월 말, 한여름
   ```
   주행거리는 만 단위로 뭉개고 날짜는 계절로만 — 손님 특정을 막는다.
3. **최근 글 제목 읽기** — 공개 RSS(`rss.blog.naver.com/tyremore_sokcho.xml`). 같은 차종 글이 있으면 **경고**만 붙인다.
4. **생성** — `claude-opus-5`, JSON 고정 출력(제목 3·본문·태그). 글 구조 4가지를 돌려 쓴다(같은 틀 반복 = 유사문서).
5. **2차 필터** `privacyFilter` — 번호판·전화 패턴, 그 손님 이름이 나오면 **버리고 한 번 다시**, 또 나오면 실패.
6. 본문에 `{{사장님_한마디}}` 자리 — 없으면 끼워 넣는다. 화면은 이 자리에 15자 이상 쓰기 전에는 복사를 안 켠다.

**지시문의 SEO 규칙** (SEO 전문가 리뷰 그대로): 결론 먼저 · 속초 2~3회만 · 소제목 3~5개 + 표/체크리스트 1개 ·
1,200~1,800자 · 가격은 범위 · 최상급 금지 · 태그 10개 이하 · 끝에 「지도 붙이세요」.

**비용**: 글 1건 ≈ 40원. 하루 3건이면 월 4천원 안쪽.

## 준비 (처음 한 번)

```
npx tsx scripts/add-blog-draft.ts        ← 코드 배포 전에. quote.referral + blog_draft
```

`.env.local` 과 Vercel 환경변수:

| 이름 | 어디서 |
|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com |
| `CRON_SECRET` | 아무 긴 문자열. Vercel 이 크론 요청에 실어 보낸다 |

⚠️ 깃허브에는 안 올라간다 (`.env.local` 은 `.gitignore`).

Vercel 함수 시간: 초안 하나에 30~60초. 크론 라우트는 `maxDuration = 300`. 플랜 제한에 걸리면
매장 PC 작업 스케줄러에서 `npm run blog-draft` 를 21:00 에 돌리면 같은 일을 한다.

## 2주 시험 뒤 판단 (현장 운영자 리뷰)

초안 20~30개 중 **실제 발행 5개 이상**이면 다음을 붙인다:
- 결제 완료 화면에 **카메라 버튼** 1~2장 → 폰에서 번호판 블러 → 블러본만 저장 (발행 때 사진 재선택 문제 해결)
- 판매 화면 「사진 게시 동의」 토글
- 웹 푸시 「초안 나왔습니다」 (지금 앱엔 푸시 인프라가 없다)

거의 안 쓰면 크론을 주 2회로 줄이고 여기서 멈춘다.

## 안 만드는 것 (그리고 왜)

| 처음 안 | 결론 | 이유 |
|---|---|---|
| 클로드 + 제미나이 두 벌 | 클로드 한 벌 + 「다르게 한 번 더」 | 3인 전원: 폰에서 덩어리 8개는 선택 피로. 사장님 확정 |
| 플레이스 리뷰 Playwright 자동 수집 | 뺌 | 플레이스 앱 푸시가 무료로 알려 준다. 셀렉터 유지비 > 효익 |
| 검색광고 API 수집·리포트 | 광고비 50만↑ 때 | 월 25만원이면 개발 공수 못 넘김. 대신 계정 수동 점검 1회 |
| 광고비 ÷ 신규 고객 (ROAS 추정) | 뺌 → `referral` 실측 | 분모에 소개·재방문이 섞여 틀린 숫자. 「어떻게 알고 오셨어요?」가 더 정확 |
| 사진 올리고 판매 건 고르기 | 사진 없이 데이터만으로 | 구리스 손으로 5장·재진입은 포기 지점. 사진은 시험 통과 후 |

검색광고 API 를 붙일 때 알아 둘 것(마케터): StatReport 는 비동기·새벽 지연 → 09:30 이후 실행,
`(날짜+키워드)` upsert 로 최근 7일 재수집(무효클릭 소급), 대조는 관리화면을 **검색광고로 필터링**한 상태에서만
(2026-03 통합 개편으로 총액이 다르다). 이 규모에서 지렛대는 입찰가가 아니라 **제외 키워드·지역·시간대**다.
