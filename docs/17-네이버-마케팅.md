## 블로그 초안이 만들어지는 과정 (`src/lib/blog-draft.ts`)

1. **글감 고르기** `pickCandidates` — 그날 성사 판매 중 타이어가 있는 것. 거래처·무상(서비스)·이미 초안 있는 건 제외.
   4본 교체 우선, 같은 차종은 하루 하나.
2. **사실 만들기** `factsText` — 지시문에 들어가는 전부. `--dry` 로 눈으로 확인할 수 있다.
   ```
   차량: 현대 그랜저 2019년식, 주행 8만km대
   시공: 미쉐린 프라이머시4 235/45R18 4본
   시기: 8월 말, 한여름
   ```
   주행거리는 만 단위로 뭉개고 날짜는 계절로만 — 손님 특정을 막는다.
3. **최근 글 제목 읽기** — 공개 RSS(`rss.blog.naver.com/tyremore_sokcho.xml`). 같은 차종 글이 있으면 **경고**만 붙인다.
4. **생성** — `claude-opus-5`, JSON 고정 출력(제목 3·본문·태그). 글 구조 4가지를 돌려 쓴다(같은 틀 반복 = 유사문서).
5. **2차 필터** `privacyFilter` — 번호판·전화 패턴, 그 손님 이름이 나오면 **버리고 한 번 다시**, 또 나오면 실패.
6. 본문에 `{{사장님_한마디}}` 자리 — 없으면 끼워 넣는다. 화면은 이 자리에 15자 이상 쓰기 전에는 복사를 안 켠다.

## v3 1단계 — 구독으로, 앱에서 (2026-09-02)

사장님이 **Claude Max 를 이미 구독 중**이라, 2주 시험은 API 키 없이 그 구독으로 한다 (요금 0원).
쓸 만하다고 판단되면 그때 키를 넣어 API 로 올린다 — 그때 고칠 곳은 `src/lib/ai.ts` 하나뿐이다.

### 왜 매장 PC 가 필요한가

구독은 **그 PC 에 로그인된 Claude Code** 를 통해서만 쓸 수 있다. Vercel 에는 그 로그인이 없다.
그래서 MARS 와 똑같은 다리를 둔다:

```
[앱 버튼]  →  blog_job 「대기」  →  [scripts/blog-agent.ts]  →  claude -p (구독)
                    ↑                        └ 진행 로그를 되쓴다 ─┐
              [앱이 3초마다 확인] ←──────────────────────────────┘
```

- `blog_job` — 주문표. `mars_run` 과 같은 모양이되 **표를 따로 뒀다**: MARS 입력은 최대 70분
  「한 번에 하나」라, 그 뒤에 서면 1~3분짜리 원고를 한 시간 기다리게 된다. 자원도 안 겹친다.
- `agent_heartbeat` — 대리인이 15초마다 찍는다. 60초 넘으면 앱이 **「매장 PC 꺼짐」**을 띄우고
  주문 자체를 안 받는다 (「대기」로 굳어 영문을 모르는 일을 막는다).
- 집는 방식은 `FOR UPDATE SKIP LOCKED` — 창이 두 개 떠도 같은 주문을 두 번 처리하지 않는다.
  자문 잠금과 달리 연결을 놓아도 안전해, 풀러 자리를 오래 물지 않는다.

### `claude -p` 를 부를 때 지키는 것 (`src/lib/ai-cli.ts`)

| | 이유 |
|---|---|
| 지시문은 **표준입력(UTF-8)** 으로, 인자는 전부 ASCII | 윈도우 argv 는 코드페이지를 타서 한글이 깨질 수 있다 |
| `.cmd` 가 아니라 **`claude.exe` 를 직접** (shell 없이) | 새 Node 는 shell 없이 `.cmd` 를 못 돌린다 |
| **`--bare` 금지**, 대신 `--safe-mode` | `--bare` 는 열쇠고리를 안 읽어 **구독 로그인이 깨진다**. API 키 전용이 된다 |
| `--json-schema` + 실패 시 울타리 벗기기 → 스키마 없이 1회 재시도 | 형식이 어긋나도 한 번은 건진다 |
| `--tools ""` | 글만 쓰게 한다. 파일을 뒤지지 않는다 |
| 쓴 모델은 **출력 토큰이 가장 많은 것**으로 기록 | 첫 키를 쓰면 곁다리 일에 쓰인 작은 모델이 기록된다 (2026-09-02 실제로 haiku 로 잘못 남았다) |
