# MARS 자동 입력

판매 등록에 쌓인 것을 MARS 「매출 주문」에 **대신 쳐 넣습니다.**

사장님이 먼저 만들어 두신 파이썬 코드
([hisonic001/MARS-auto-register](https://github.com/hisonic001/MARS-auto-register))의
화면 조작 순서와 선택자를 그대로 가져왔습니다. 달라진 것은 **읽어 오는 곳**입니다.

```
전:  customers.xlsm      ← 사람이 엑셀에 옮겨 적어야 했다
후:  판매 등록 화면        ← 팔면서 이미 기록된 것을 그대로 쓴다
```

엑셀 중간 단계가 통째로 사라집니다. 그리고 우리 쪽에는 이미
**MARS 품번**과 **부가세 포함 단가**가 들어 있어 변환 없이 그대로 넣습니다.

---

## 🔴 전기(Posting)는 하지 않습니다

매출 주문을 **만들어 채워 두기만** 합니다. 확인하고 전기하는 것은 사장님입니다.

MARS 는 본사 자산이고, 잘못 전기하면 되돌리는 것이 우리 손을 떠납니다.
사장님 파이썬 코드도 최종 「확인」 직전에 `page.pause()` 로 멈춰 있었습니다 — 같은 원칙입니다.

## 🔴 고객·차량을 새로 만들지 않습니다

파이썬 코드에는 신규 고객 생성이 있었지만 **일부러 뺐습니다.**
그 화면에는 개인정보 활용 동의 체크와 「고객 서명」 항목이 있습니다.
**손님이 서명하는 것을 프로그램이 대신 체크하게 둘 수 없습니다.**

MARS 에 없는 차량은 건너뛰고 알려 드립니다. 등록은 직접 해 주십시오.

---

## 준비 (처음 한 번)

`.env.local` 에 MARS 계정을 넣습니다.

```
MARS_ID=아이디
MARS_PASSWORD=비밀번호
```

⚠️ 이 파일은 **깃허브에도 Vercel 에도 올라가지 않습니다.** 사장님 PC에만 있습니다.

브라우저는 이미 깔려 있는 Chrome 을 씁니다 — 따로 받을 것이 없습니다.

## 쓰는 법

```
npm run mars                대기열 전부 처리 (창이 보이게 열립니다)
npm run mars -- --dry       무엇이 대기 중인지만 보여주고 아무것도 안 합니다
npm run mars -- --limit 1   한 건만 — 처음 시험하실 때
```

**처음에는 `--limit 1` 로 한 건만 해 보시고**, 결과가 맞으면 전체로 돌리십시오.

## 하는 일

1. 로그인 (`mars.tyremore.co.kr`)
2. 대기열의 판매 한 건씩:
   - 「고객 정보 검색」에서 **번호판으로** 찾기
   - 없으면 건너뜀
   - 「판매 내역 → 신규 → 신규 매출 주문」
   - 문서 날짜·완료 일자 입력
   - 품목 표에 **유형 / 번호 / 수량 / 단가 부가세 포함** 채우기
     (타이어·부품 → `상품`, 공임 → `서비스`)
3. 다 하면 브라우저를 **열어 둔 채로** 멈춥니다 — 확인하시고 전기하십시오

## 잘 안 될 때

| 증상 | 뜻 |
|---|---|
| `로그인 실패` | 아이디·비밀번호 확인. MARS 가 느릴 때도 납니다 |
| `MARS 에 없는 차량입니다` | 그 손님은 MARS 에 고객·차량을 먼저 만들어 주셔야 합니다 |
| `MARS 품번이 없어 건너뜁니다` | 우리 쪽에서 자체 등록한 상품입니다 (NEW-…). MARS 품번이 생기면 이어집니다 |
| 화면이 바뀌어서 멈춤 | MARS 가 업데이트되면 선택자가 어긋납니다. 그때 다시 맞춰야 합니다 |

⚠️ 화면 조작 방식의 숙명입니다. **MARS 화면이 바뀌면 멈춥니다.**
   더 튼튼한 길은 Business Central 의 웹 서비스(OData)인데,
   MARS 메뉴의 「웹 서비스 설정」에서 본사가 이미 열어 두었는지 **보기만** 하면 알 수 있습니다.
   열려 있다면 화면 조작 없이 훨씬 안정적으로 넣을 수 있습니다.

## 🚨 짚고 넘어갈 것 — MARS-auto-register 는 공개 저장소입니다

참고하려고 열어 보니 이런 파일이 **공개**로 올라가 있습니다.

```
customers.xlsm    1.1 MB   고객 정보
customers3.xlsm   1.1 MB
customers3.xlsx   458 KB
error_page_content.html  119 KB   MARS 화면이 통째로 저장됨
```

실명·휴대폰·차량번호가 인터넷에 그대로 열려 있는 상태입니다.
지금 하시는 일과 별개로, **저장소를 비공개로 돌리시는 것**을 권합니다
(Settings → General → 맨 아래 Change visibility → Private).

⚠️ 비공개로 바꿔도 **이미 받아 간 것은 되돌릴 수 없습니다.** 그래도 지금 막는 것이 낫습니다.
