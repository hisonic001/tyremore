# 13. 배포 안내 (Vercel)

2026-08-01 · 사장님이 직접 하시는 부분만 정리했습니다.

---

## 왜 배포하나

지금은 **사장님 PC가 켜져 있어야만** 접속됩니다 (`http://192.168.0.12:3000`).
배포하면 매장 태블릿·폰·집 어디서든 열립니다.

> ⚠️ 배포하면 **인터넷에 열립니다.** 고객 실명·휴대폰 2,593건과 매입가가 들어 있으므로
> 로그인이 반드시 먼저입니다. 이미 넣어 두었습니다 — 로그인 없이는 어떤 화면도 안 열립니다.

---

## 1단계 — 계정 만들기 (지금 바로)

터미널에 `!` 를 붙여 실행하세요. **비밀번호는 물어볼 때 입력**하시면 되고, 화면에 안 보입니다.

```
! cd C:\dev\tyremore; npx tsx scripts/create-user.ts owner 사장님 owner
```

정비사 계정도 같은 방식으로:

```
! cd C:\dev\tyremore; npx tsx scripts/create-user.ts tech1 김정비 tech
```

| 역할 | 보이는 것 |
|---|---|
| `owner` | 판매가 + **매입원가·마진** |
| `tech` | 판매가만 |

> 비밀번호는 **8자 이상**으로 하세요. 인터넷에 열리는 화면입니다.
> 같은 명령을 다시 실행하면 비밀번호가 바뀝니다.

---

## 2단계 — Vercel 가입 · 저장소 연결

1. <https://vercel.com/signup> → **Continue with GitHub**
2. **Add New… → Project**
3. `hisonic001/tyremore` 옆 **Import**
4. 설정은 건드리지 마세요. Next.js 프로젝트로 자동 인식됩니다.

---

## 3단계 — 환경변수 2개 (가장 중요)

Import 화면의 **Environment Variables** 에 두 줄을 넣습니다.
값은 `C:\dev\tyremore\.env.local` 파일에 있는 것을 **그대로 복사**하세요.

| 이름 | 값 |
|---|---|
| `DATABASE_URL` | `.env.local` 의 같은 줄 (Supabase 접속 문자열) |
| `AUTH_SECRET` | `.env.local` 의 같은 줄 (긴 임의 문자열) |

> ⚠️ `IMPORT_DATA_DIR` 은 **넣지 마세요.** 이관 스크립트 전용이고, 서버에는 엑셀이 없습니다.
> ⚠️ 이 두 값은 비밀입니다. 메신저·메일로 보내지 마세요.

**Deploy** 를 누르면 2~3분 뒤 주소가 나옵니다: `https://tyremore-xxxx.vercel.app`

---

## 4단계 — 확인

1. 나온 주소를 폰에서 엽니다 → **로그인 화면이 떠야 정상입니다**
2. 1단계에서 만든 계정으로 로그인
3. 차량번호·규격을 검색해 봅니다

**한 번 로그인하면 그 기기에서 90일간 유지됩니다.** 매장 태블릿은 한 번만 하면 됩니다.

---

## 앞으로 — 고치면 자동으로 반영됩니다

```
코드 수정 → git push → 1~2분 뒤 배포 완료
```

제가 고친 내용이 자동으로 올라갑니다. 사장님이 하실 일은 없습니다.

---

## 문제가 생기면

| 증상 | 원인 |
|---|---|
| `AUTH_SECRET 이 설정되지 않았습니다` | 3단계 환경변수 누락 |
| 로그인해도 계속 로그인 화면 | `AUTH_SECRET` 이 로컬과 다름 |
| 검색이 안 됨 / 오류 | `DATABASE_URL` 오타 — 끝의 `?` 뒤까지 전부 복사했는지 확인 |
| 화면이 깨져 보임 | 브라우저에서 `Ctrl+Shift+R` |

## 나중에 자체 서버로 옮길 때 (D-06)

Vercel에 묶이는 코드를 쓰지 않았습니다. 사무실 PC로 옮기실 때:

```
git clone https://github.com/hisonic001/tyremore
docker compose up -d
```

`docker-compose.yml` 을 처음부터 함께 만들어 두었습니다.
