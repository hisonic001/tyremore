# 10. 화면 설계 (1차 오픈)

2단계 솔루션 아키텍트 산출물 | 2026-07-31

> **모든 화면은 "엑셀보다 빠른가?"를 통과해야 한다.** (`01-업무분석서.md` §5)
> 정비사는 **장갑을 끼고, 화면은 더럽고, 고객은 앞에 서 있다.**

---

## 1. 설계 원칙 5가지

| # | 원칙 | 구체적으로 |
|---|---|---|
| 1 | **검색창은 하나** | 무엇을 검색할지 고르게 하지 않는다. 시스템이 판별한다 (`08` 6장) |
| 2 | **버튼은 크게** | 최소 **48×48px**. 목록 항목은 높이 **64px** 이상 |
| 3 | **누르는 횟수를 센다** | 상담 시작 → 견적 완성까지 **7번 이내** |
| 4 | **기본값을 채워둔다** | 부대비용은 **체크된 상태**로 뜬다. 빼는 건 쉽고, 넣는 건 잊는다 |
| 5 | **숫자는 크게, 라벨은 작게** | 고객에게 화면을 돌려 보여줄 수 있어야 한다 |

## 3. ⭐ 화면 1 — 통합 검색 (홈)

앱을 켜면 **이 화면**이다. 정비사가 가장 많이 보는 화면.

```
┌───────────────────────────────────┐
│  타이어모어 속초          김정비 ▾ │
├───────────────────────────────────┤
│                                   │
│  ┌─────────────────────────────┐ │
│  │ 🔍                          │ │  ← 커서 자동 포커스
│  │  차량번호·이름·전화·규격     │ │     스캔도 여기로 들어옴
│  └─────────────────────────────┘ │
│                                   │
│  ┌──────────┐  ┌──────────┐      │
│  │  📥 입고  │  │  📤 출고  │      │  ← 64px 이상
│  └──────────┘  └──────────┘      │
│  ┌──────────┐  ┌──────────┐      │
│  │  📦 재고  │  │  📋 견적  │      │
│  └──────────┘  └──────────┘      │
│                                   │
│  최근 본 차량                      │
│  ┌─────────────────────────────┐ │
│  │ 12가3456  홍길동  그랜저     │ │
│  │ 34나5678  김철수  쏘렌토     │ │
│  └─────────────────────────────┘ │
└───────────────────────────────────┘
```

**입력 자동 판별** (`08` 6장):

| 입력 | 판별 | 이동 |
|---|---|---|
| `12가3456` | 차량번호 | 화면 2 |
| `3456` | 뒷 4자리 | 후보 목록 → 화면 2 |
| `010…` | 전화 | 고객 → 화면 2 |
| `홍길동`·`한진택배` | 이름·메모 | 고객 목록 |
| `225/45R17`·`2254517`·`225 45 17` | 규격 | 화면 3 |
| 13자리 숫자 | 바코드 | 상품 상세 |
| `MBA-039`·`SM188` | **부품 품번** | 부품 재고 (D-12) |

> 정비사가 **모드를 고르지 않는다.** 고객이 말하는 대로 받아치면 된다.

> ⚠️ 판별이 애매한 입력(예: `현대`)은 **여러 종류의 결과를 섹션으로 나눠 함께** 보여준다.
> "고객 3명 / 부품 12종" 처럼. 틀린 판정으로 아무것도 못 찾는 것보다 낫다.

## 4. 화면 2 — 차량·고객 상세

```
┌───────────────────────────────────┐
│ ← 12가3456                        │
├───────────────────────────────────┤
│  홍길동            📞 010-****-5678│  ← 목록은 마스킹, 누르면 전화
│  [한진택배]                        │  ← 메모도 같이 보여준다
│                                   │
│  현대 그랜저 · 2008년식            │
│  주행 182,300km                    │
│  최근 장착  225/45R17              │  ← last_fitted_size
│                                   │
│  ┌─────────────────────────────┐ │
│  │   이 차 규격으로 견적 →      │ │  ← 가장 큰 버튼
│  └─────────────────────────────┘ │
│                                   │
│  이력                              │
│  2025-11-03  타이어 4본 + 장착     │
│  2024-06-12  엔진오일              │
│                                   │
│  ⚠ 같은 번호 사용: 홍길동님 외 1명 │  ← family_group
└───────────────────────────────────┘
```

> **"이 차 규격으로 견적"** 버튼이 핵심이다. 규격을 다시 입력하지 않는다.
> 이력이 있으면 **누른 순간 화면 4로 직행**한다.

## 5. 화면 3 — 규격 검색 → 재고·가격

```
┌───────────────────────────────────┐
│ ← 225/45R17                       │
├───────────────────────────────────┤
│  🟢 재고 있음 (3종 11본)           │
│                                   │
│ ┌───────────────────────────────┐ │
│ │ 미쉐린 PS4         재고 4본  ✓│ │
│ │ 판매가  ⚠ 할인율 미설정        │ │  ← 공란이어도 막지 않는다
│ │ 기표가  328,000원              │ │
│ └───────────────────────────────┘ │
│ ─────────────────────────────────│
│  ⚪ 미등록 — 창고 확인 필요 (8종)  │  ← ⭐ 접지 않는다
│ ┌───────────────────────────────┐ │
│ │ 한국 K127          ⚪ 미등록   │ │
│ │ 기표가  240,000원              │ │  ← 견적은 그대로 낼 수 있다
│ │              [ 재고 등록 ]     │ │  ← 있으면 그 자리에서 넣는다
│ └───────────────────────────────┘ │
│ ┌───────────────────────────────┐ │
│ │ 금호 TA31          ⚪ 미등록   │ │
│ └───────────────────────────────┘ │
│ ─────────────────────────────────│
│  🔴 0본 · 소진 (주문 필요)  4종 ▾ │  ← 이것만 접어둔다
└───────────────────────────────────┘
```

> **재고 있는 것이 위, 소진된 것만 접어서 아래.**
> 지금 팔 수 있는 것을 먼저 보여주는 게 상담 속도를 결정한다.
> 사장님 계정에는 각 줄에 **마진**이 추가로 표시된다.

### ⭐ 「미등록」은 「없음」과 다르다 — 접지 않는다

오픈 시점에 시스템이 아는 재고는 **미쉐린뿐**이다. 한국·금호·넥센은 창고에 있어도
시스템에는 없다. 이걸 `재고 없음`으로 표시하면 **화면이 거짓말을 한다.**

| 상태 | 표시 | 정비사가 할 일 |
|---|---|---|
| 🟢 있음 | **4본** | 그냥 판다 |
| ⚪ **미등록** | **미등록** | **창고를 본다.** 있으면 [재고 등록] |
| 🔴 소진 | **0본** | 주문한다 |

- **미등록은 접지 않는다.** 접으면 안 보이고, 안 보이면 못 판다.
- **미등록이어도 견적은 그대로 나온다.** 기표가와 할인율은 마스터에 다 있다.
  재고 등록 여부가 **판매를 막아서는 안 된다.**
- [재고 등록]을 누르면 화면 7 입고로 바로 넘어간다 → 그 상품이 켜진다(`stock_tracked`).
- **창고를 볼수록 미등록이 줄어든다.** 등록을 따로 하는 날을 잡을 필요가 없다.

## 6. ⭐⭐ 화면 4 — 견적 작성 (가장 중요)

```
┌───────────────────────────────────┐
│ ← 견적  12가3456 홍길동            │
├───────────────────────────────────┤
│ 한국 K127  225/45R17               │
│                                   │
│   [ − ]     4 본     [ + ]        │  ← 큰 버튼
│                                   │
│ 기표가          240,000원          │
│ 할인율     [ 30 ] %                │  ← 양방향 (D-05)
│ 판매가     [ 168,000 ] 원          │
│                          672,000원 │
│ ─────────────────────────────────│
│ 부대비용                    ▾      │
│ ☑ 장착 (17인치)  20,000 × 4  80,000│  ← 기본 체크
│ ☑ 휠밸런스 2개당 20,000 × 2  40,000│  ← ⭐ 4본이면 2회
│ ☐ 얼라인먼트 국산 승용       60,000│  ← 국산 자동 판정
│ ☐ 폐타이어 처리비                  │
│ ─────────────────────────────────│
│         합계      792,000원        │  ← 가장 크게
│         (사장님만) 마진 214,000원   │
│                                   │
│ ┌─────────┐ ┌───────────────────┐│
│ │  저장   │ │   고객에게 보여주기 ││
│ └─────────┘ └───────────────────┘│
└───────────────────────────────────┘
```

### 이 화면에서 자동으로 일어나는 것

| 자동 처리 | 근거 |
|---|---|
| 17인치 → **장착 20,000원** 자동 선택 | `service_item.rim_min/max` |
| 4본 → **휠밸런스 2회** (⌈4÷2⌉) | `qty_rule='per_2_units'` ⭐ |
| 현대 → **국산 얼라인먼트 60,000원** | `vehicle_maker.is_imported=false` |
| 할인율 30% 입력 → 판매가 자동 계산 | 양방향 (D-05) |
| 판매가 168,000 입력 → 할인율 역산 | 〃 |
| 마진 실시간 계산 | 사장님 계정만 |

> ⚠️ **휠밸런스 ×2가 이 화면의 존재 이유 중 하나다.**
> 지금은 사람이 계산하다 놓치면 그대로 매출 누락이다. 시스템은 안 잊는다.

### 할인율이 비어 있을 때 (D-05)

```
┌───────────────────────────────────┐
│ 미쉐린 PS4                         │
│ 기표가      328,000원              │
│ 할인율   [    ] %    ⚠ 미설정      │
│ 판매가   [        ] 원             │
│ ※ 둘 중 아무거나 넣으면 나머지 자동 │
└───────────────────────────────────┘

     ↓ 입력하면 (사장님 계정만)

┌───────────────────────────────────┐
│ 이 할인율(25%)을 기본값으로 저장?  │
│  ○ 이 상품만   ○ 이 모델 전체      │
│  ○ 미쉐린 전체 ○ 저장 안 함        │
└───────────────────────────────────┘
```

> 정비사 계정은 **이번 건에만 적용**된다. 기본값 저장은 사장님만 (`08` 3장).
> **파는 만큼 마스터가 저절로 완성된다.**

### 「고객에게 보여주기」 모드

누르면 **매입원가·마진·할인율이 사라지고** 큰 글씨 합계만 남는다.
화면을 그대로 고객 쪽으로 돌린다.

## 7. 화면 6·7 — 입고 / 출고 스캔 (태블릿)

```
┌─────────────────────────────────────────┐
│  📥 입고                        김정비 ▾ │
├─────────────────────────────────────────┤
│                                         │
│        바코드를 스캔하세요               │
│         ▐▌▐▌▐ ▌▐▌▐▌                    │  ← 커서 신경 안 써도 됨
│                                         │
│ ─────────────────────────────────────── │
│ 미쉐린 PRIMACY A/S 245/45R18            │
│                                         │
│   DOT [ 1826 ]   수량 [ − ] 14 [ + ]   │  ← ⭐ DOT별 입력
│   DOT [      ]   수량 [ − ]  0 [ + ]   │  ← 필요하면 줄 추가
│                            합계  14본   │
│                                         │
│   ※ DOT를 모르면 비워도 됩니다           │
│ ┌─────────────────────────────────────┐ │
│ │            입고 확정                 │ │
│ └─────────────────────────────────────┘ │
│ ─────────────────────────────────────── │
│ 오늘 입고 22본                           │
│ 14:22  미쉐린 PRIMACY 14본  DOT 1826    │
│ 13:50  금호 TA31 8본        DOT 0726    │
└─────────────────────────────────────────┘
```

> ⭐ **DOT 입력 방식은 사장님 엑셀을 그대로 옮긴 것이다** (D-12).
> 엑셀에 `1826[14]`라고 적고 계셨다 — 이미 이 형태로 일하고 계신다.
> 한 박스가 전부 같은 DOT면 **한 줄로 끝난다** (실데이터에서 흔하다).

- 스캔 → 상품 자동 인식 → DOT별 수량 → 확정 → **1본씩 재고 행 자동 생성** (D-02)
- **처음 보는 바코드** → "새 상품 등록" 화면으로 자동 유도 → 마스터가 쓰면서 채워진다
- 출고는 같은 구조 + **사유 선택** (판매 / 보관 / 반품 / 폐기)
  → 출고 시 **DOT 오래된 것부터 자동 선택** (선입선출)

### ⭐ 스캔 없이도 넣을 수 있어야 한다 (미쉐린 외 브랜드용)

1주차 엑셀 이관으로 들어오는 것은 미쉐린 57종뿐이다. **나머지 브랜드는 사장님이
프로그램을 써 보시면서 이 화면으로 직접 넣으신다** *(2026-08-01 확정)*.
그러려면 **박스를 들고 스캐너 앞에 갈 필요가 없어야 한다.**

```
┌─────────────────────────────────────────┐
│ 📥 입고        [ 스캔 ] [ 검색 ] [ 일괄 ]│
├─────────────────────────────────────────┤
│ 🔍 225/45R17  또는  K127                │  ← 규격·모델명으로 찾는다
├─────────────────────────────────────────┤
│ 한국 K127  225/45R17 94W    ⚪ 미등록    │
│   DOT [ 0726 ]  수량 [ − ] 8 [ + ]      │
│                          [ 입고 확정 ]  │
└─────────────────────────────────────────┘
```

- **[검색] 탭** — 바코드 없이 규격·브랜드·모델로 찾아 바로 입고. 부품과 같은 경로다.
- **[일괄] 탭** — 한 브랜드를 쭉 훑을 때. 확정해도 화면이 안 닫히고
  **검색창으로 커서가 돌아간다.** 30종을 앉은자리에서 넣을 수 있다.
- **DOT는 여전히 선택.** 나중에 채운 재고라 DOT를 모를 수 있다 → 비워도 통과 (D-02).
- 입고가 확정되면 그 상품의 `stock_tracked`가 켜지고 **⚪ 미등록 표시가 사라진다.**

> 재고 **수정**은 화면 8c(재고 실사)에서 한다. 넣는 건 여기, 고치는 건 거기다.
> 둘 다 **2주차**에 나오므로, 프로그램을 확인하시고 브랜드를 넓히실 수 있다.

### 부품 입출고는 스캔이 아니라 검색이다

부품에는 **바코드가 없다** (D-12). 같은 화면에서 검색으로 처리한다.

```
┌─────────────────────────────────────────┐
│ 🔍 MBA-039  또는  제네시스              │  ← 품번·적용차종 둘 다
├─────────────────────────────────────────┤
│ MBA-039  제네시스 DH / 펠리세이드        │
│ 재고     미확인        [ 지금 세기 ]     │  ← ⭐ 수량을 모른다
└─────────────────────────────────────────┘
```

- 부품은 **1행에 수량**으로 관리 (`stock_item.qty`)
- 차량을 조회한 상태라면 **그 차에 맞는 부품만** 위로 올려준다

## 7-B. ⭐ 화면 8c — 재고 실사 (2주차)

부품 재고 수량은 실물과 맞지 않는다 (D-12 5번). **모르는 것을 아는 척하지 않는다.**

```
┌─────────────────────────────────────────┐
│ 📋 재고 실사              미확인 265종   │
│ [ 부품 ] [ 타이어 ] [ 전체 ]            │
├─────────────────────────────────────────┤
│ 🔍 검색 또는 스캔                        │
├─────────────────────────────────────────┤
│ MBA-001  현대 전차종                     │
│ 미확인 →  [ − ]  8  [ + ]   [ 확정 ]    │
│ ─────────────────────────────────────── │
│ MBA-004  포터 / 봉고                     │
│ 미확인 →  [ − ]  0  [ + ]   [ 확정 ]    │
│ ─────────────────────────────────────── │
│ MBA-039  제네시스 DH / 펠리세이드         │
│ ✅ 5개  7/31 확인  김정비                │  ← 이미 끝난 것은 아래로
└─────────────────────────────────────────┘
```

**동작:**
- 확정하면 `verified_at`·`verified_by`가 찍히고 **`미확인` 표시가 사라진다**
- 확정 안 한 것이 위로 올라온다 → **남은 일이 눈에 보인다**
- 타이어는 스캔으로도 확정 가능 (**4주차 타이어 실사에 그대로 쓴다**)

- **타이어 재고 수정도 여기서 한다.** 실물과 다르면 숫자를 고치고 확정하면 된다
  → 미쉐린 외 브랜드를 넣으신 뒤 틀린 곳을 바로잡는 경로가 이것이다 (2026-08-01)

> 한 번에 265종을 다 셀 필요가 없다. **자주 나가는 것부터 저절로 확정된다.**
> 출고하려는데 `미확인`이면 그 자리에서 세게 되고, 그게 실사다.

> 이 화면은 부품 때문에 앞당겼지만 **어차피 4주차에 필요했다.**
> 오픈 직전 타이어 실사로 재고 기준점을 맞추는 것이 원래 계획이다.

## 8. ⭐ 화면 9 — MARS 입력 대기열 (4주차 · 본안)

본사 협의가 불가해 자동 연동 경로가 없다(D-08 개정). **이 화면이 최종안이다.**
왼쪽에 이 화면, 오른쪽에 MARS를 띄우고 쓰는 것을 전제로 설계한다.

```
┌────────────────────────────────────────────────────────┐
│ MARS 입력 대기열                        미입력 7건      │
├────────────────────────────────────────────────────────┤
│ ⚠ 3일 이상 밀린 건 2건                                  │
├────────────────────────────────────────────────────────┤
│ ▶ 07-29  12가3456  홍길동   792,000원   [4일 경과] 🔴  │
│ ▼ 07-31  34나5678  김철수   468,000원                  │
│                                                        │
│   ① 연락처 검색/등록          [전체 복사]              │
│      이름   김철수                          [복사]      │
│      휴대폰 01098765432                     [복사]      │
│      ※ MARS 「연락처」에 등록 (고객 계정 아님) ⭐        │
│                                                        │
│   ② 차량 등록                                          │
│      번호판 34나5678                        [복사]      │
│      제조사 기아 / 쏘렌토 / 2021           [복사]      │
│                                                        │
│   ③ 신규 매출 주문                                     │
│      금호 TA31 225/45R17   4본  142,000    [복사]      │
│      장착 17인치            4     20,000    [복사]      │
│      휠밸런스 2개당         2     20,000    [복사]      │
│                                                        │
│   ④ 전기(Posting)  ← 반드시 사람이 확인하고 누름 ⚠     │
│                                                        │
│   [ MARS 입력 완료 ]        [ 보류 ]                   │
│                             ↓ 다음 건으로 자동 이동     │
└────────────────────────────────────────────────────────┘
```

**설계 포인트:**
1. **MARS 입력 순서(①~⑤) 그대로 배열** — 화면을 왔다 갔다 하지 않는다
2. **「연락처」임을 명시** — 「고객」 계정을 새로 만들면 안 된다 (D-10)
3. **전체 복사 + 항목별 복사** 둘 다
4. **완료 누르면 다음 건으로 자동 이동** — 하루치 몰아 입력용
5. **전기는 자동화하지 않는다.** 안내만 하고 사람이 누른다 (D-08 원칙)

> 목표는 MARS 입력을 없애는 게 아니라 **옮겨 적는 수고를 0에 가깝게** 만드는 것이다.

## 10. 상담 흐름 — 누르는 횟수

**목표: 고객이 서 있는 30초 안에 견적 제시** (`02-MVP-정의서.md` §1)

```
① 홈에서 차량번호 입력          (1회 + 타이핑)
② 「이 차 규격으로 견적」 누름   (2회)
③ 상품 선택                     (3회)
④ 본수 조정                     (4회)   ← 4본이 기본값이면 생략
⑤ 부대비용 확인                 (5회)   ← 기본 체크라 대개 그대로
⑥ 「고객에게 보여주기」          (6회)
⑦ 저장                          (7회)
```

**7번 이내. 재방문 고객이면 실측 20~30초.**

신규 고객은 차종 입력이 한 번 더 들어간다(외부 API 미사용 — D-04).
그래도 **한 번 넣으면 그 차는 영원히 자동**이다.

## 11. 시각 규칙
