# 02. MVP 정의서 — 1차 오픈 (4주)

확정안: **A안 (재고 → 상담·견적)** · 목표 오픈: 착수일 + 4주

---

## 1. 1차 오픈의 목표 (한 문장)

> **고객이 서 있는 30초 안에, 폰으로 재고와 가격을 확인해 견적을 제시한다.**

이 한 문장을 못 하면 1차 오픈은 실패다. 나머지는 전부 이걸 위한 부속이다.

## 2. 4주 계획

### 1주차 — 마스터 데이터 구축 (**대부분 MARS에서 이관**)
| 산출물 | 내용 | 출처 |
|---|---|---|
| 상품 마스터 | 브랜드·패턴·규격·하중지수·속도기호·바코드·**기표가** | ✅ **MARS 「상품」 10,691건 확보** |
| 고객 테이블 | 이름·휴대폰·메모 | ✅ **MARS 「연락처」 2,603건 확보** ⭐ |
| 차량 테이블 | 번호판·제조사·모델·연식·주행거리 | ✅ **MARS 「차량 목록」 2,574건 확보** |
| **서비스·공임** | 경정비·타이어 부대비용 단가 | ✅ **MARS 「패스트핏 서비스」 69건 확보** ⭐ |
| 초기 재고 (타이어) | 미쉐린 57종 290본 + DOT | ✅ **확보. MARS 품번 100% 매칭** (D-12) |
| 초기 재고 (부품) | 약 265종 — **수량은 `미확인`** | ⚠️ 품목만 이관. 실물과 안 맞음 (D-12) |
| 가격 규칙 **틀** | 매입/판매 할인율 규칙 테이블 — **값은 공란으로 시작** | 화면에서 누적 |
| **데이터 정제** | 제조사 48종→25종 통합 / 중복 연락처 139건 / 이상치 14건 보정 | `07` 6장 |
| **MARS 매핑 설계** | `mars_status`·`mars_synced_at`·`mars_ref_no` + **`mars_contact_no`** | D-10 |

> 🎁 **1주차 마스터가 재고 엑셀 하나 빼고 전부 확보됐다.**
> 게다가 3개월차 예정이던 **경정비 공임**과 3주차 블로커였던 **타이어 부대비용**,
> 2개월차 블로커였던 **보관료**까지 서비스 목록 69건에 들어 있었다.

> ⭐ **주의 — 고객 식별자**: MARS 「고객」은 회계 계정 2건뿐이다.
> 실제 고객은 **「연락처」(`C583-…`)** 다. `mars_contact_no`를 쓴다. (D-10 / `docs/07`)

> 🔑 **사장님 준비물**: **재고 엑셀 하나만 남았다.** (+ API 키 스크린샷 마스킹)

### 2주차 — 바코드 입출고 (현장용)
| 화면 | 동작 |
|---|---|
| 입고 | 바코드 스캔 → 상품 자동 인식 → **DOT별 수량 입력** → 1본 단위 재고 자동 생성 |
| **입고 — 검색·일괄** ⭐ | 스캐너 없이 규격·모델로 찾아 입고. **미쉐린 외 브랜드 등록용** |
| 출고 | 바코드 스캔 → 차감(**DOT 오래된 것부터**). 사유(판매/보관/반품) 선택 |
| 재고 현황 | 규격·브랜드 검색, 실시간 잔량. **타이어+부품 통합.** 폰·태블릿 최적화 |
| **재고 실사·수정** ⭐ | 미확인 항목 확정 + 수량 정정. 부품용이자 **4주차 타이어 실사 겸용** |
| 재고 노후화 | DOT 기준 오래된 재고 경고 (2024년산 5본 등) |

> 처음 보는 바코드는 "새 상품 등록" 화면으로 자동 유도 → 마스터가 쓰면서 채워진다.
> **부품은 바코드가 없으므로 검색으로 처리한다** (D-12).

> ⭐ **미쉐린 외 브랜드는 이 주차부터 사장님이 직접 넣으신다** (D-12 6번).
> 프로그램이 도는 것을 보신 뒤 입고·실사 화면으로 브랜드를 넓히는 것이 계획이다.
> 그때까지 그 상품들은 `0본`이 아니라 **`⚪ 미등록`**으로 표시된다 — **견적은 그대로 나온다.**

### 3주차 — 상담·견적 (핵심)
| 화면 | 동작 |
|---|---|
| 차량번호 조회 | 재방문 차량이면 **차종·연식·주행거리·이력**이 바로 뜸 (2,574대 이관 — 오픈 즉시) |
| 신규 차량 등록 | 조회 결과 없으면 **차종 수기 입력** (외부 API 미사용 — D-04). 이후엔 자동 |
| 규격 검색 | 규격 선택 → **보유 재고 우선**, 가격대별 추천 목록 |
| 견적서 | 기표가 → 할인율 자동 적용 → **현장에서 금액 직접 수정 가능** → 합계 |
| **부대비용 자동 추가** ⭐ | 장착 공임·휠밸런스를 **규격의 인치로 자동 선택**, 수량 규칙 자동 적용 |
| **국산/수입 공임 자동 판정** | 차량 제조사를 보고 공임을 고름 (얼라인먼트 60,000 vs 80,000 등) |
| **할인율 인라인 입력** | 할인율 ↔ 판매가 **양방향 자동 계산**. 입력값을 상품/모델/브랜드 범위로 저장 → `06-가격계산-설계.md` |
| **마진 표시 (사장님 전용)** | 매입 할인율이 있으면 실시간 마진 표시. 정비사 화면에는 미노출 |
| 견적 저장 | 고객·차량과 함께 저장. 나중에 "그때 얼마였죠?" 대응 |

### 4주차 — MARS 입력 대기열 + 현장 테스트 및 오픈
| 항목 | 내용 |
|---|---|
| **MARS 입력 대기열** | 아직 MARS에 안 넣은 건 목록 + 입력 순서대로 배열 → **누락 구조적 차단** |
| ↳ 원클릭 전체 복사 | 한 건의 모든 필드를 MARS 입력 순서대로 한 번에 복사 |
| ↳ 화면 분할 전제 | 왼쪽 우리 시스템 / 오른쪽 MARS 를 상정한 레이아웃 |
| ↳ 일괄 처리 모드 | 하루치 몰아 입력 시 다음 건으로 자동 이동 |
| ↳ 경과일 경고 | 3일 이상 밀린 건 상단 표시 |
| 현장 테스트 | 실제 상담 10건, 입출고 3일치를 시스템으로 병행 처리 |
| 피드백 반영 | 정비사 의견 반영 (특히 "느리다" 지점 집중 수정) |
| 오픈 | 1페이지 사용 설명서 작성 → **오픈** |

> ⭐ **본사 협의가 불가하므로 MARS 자동 연동(OData) 경로는 폐기됐다.**
> 입력 대기열은 이제 "보장안"이 아니라 **본안**이다. 그만큼 완성도를 올려 잡았다.
> 목표: MARS 입력을 없애는 게 아니라 **옮겨 적는 수고를 0에 가깝게** 만드는 것.
> 상세는 `04-MARS-연동방안.md` 5장.

## 3. 1차 오픈에 포함 / 제외

### ✅ 포함
- 상품·가격 마스터, 엑셀 재고 업로드
- **MARS 데이터 가져오기** (연락처 2,603 / 차량 2,574 / 서비스·공임 69)
- **서비스·공임 마스터** ← 3개월차에서 앞당김 (D-10)
- 바코드 입고·출고, 1본 단위 재고
- 차량번호 기반 이력 조회
- 규격 검색 → 재고·가격 추천
- 할인율 자동 적용 견적서 (현장 수정 가능)
- **MARS 입력 대기열 (누락 방지)**
- 폰·태블릿·PC 반응형

### ❌ 제외 (후속 단계)
| 기능 | 시기 | 제외 이유 |
|---|---|---|
| 타이어 보관 관리 | 2개월차 | 범위가 독립적. 4주에 넣으면 견적이 부실해짐 |
| 작업지시서·정비이력 | 3개월차 | 고객·차량 DB가 어느 정도 쌓인 뒤가 효율적 |
| 매출·정산·제휴대조 | 4개월차 | 거래 데이터가 쌓여야 의미가 생김 |
| **MARS 자동 투입 (OData API)** | ❌ **폐기** | **본사 협의 불가 → 경로 없음.** 4주차 입력 대기열이 최종안 |
| MARS 화면 자동화 (Playwright) | 미정 | 오픈 후 1개월 운영해 보고 사장님이 판단. 위험 감수 전제 |
| 유료 차량정보 API | ❌ **미도입** | **자사 DB 축적으로 대체 (D-04).** 신규 차량만 최초 1회 수기 입력 |
| 문자 알림 | 2개월차 | 보관 만료 알림과 함께 도입 |
| 법인 외상·미수금 | 보류 | 사장님이 문제로 꼽지 않음 |
| DOT 필수 입력 | 점진 | 입력 부담. 필드는 만들되 선택 항목으로 |

## 4. 성공 판정 기준 (오픈 4주 후 측정)

| 지표 | 목표 |
|---|---|
| 상담 견적 소요 시간 | 창고 확인 없이 **1분 이내** |
| 시스템 재고 vs 실재고 정확도 | **미쉐린 타이어 기준 95% 이상** |
| 부품 재고 확정률 | 자주 나가는 **상위 30종 확정** (전체 265종 아님) |
| 정비사 자발적 사용률 | 출고 건의 **80% 이상**이 시스템 경유 |
| 엑셀 중복 입력 | **중단** |
| MARS 입력 누락 | **0건** (대기열로 추적) |

> 3번(자발적 사용률)이 가장 중요하다. 이게 낮으면 나머지 지표는 의미가 없다.

## 5. 진행 전 사장님 확인 필요 사항

**✅ 착수 조건 전부 해소 (2026-08-01) — 1주차 시작 가능**
- ✅ 재고 엑셀 확보 — 미쉐린 57종 290본 + DOT
- ✅ 미쉐린 `26.7.16재고UDT` = 최신 확정. `틀` 시트 폐기
- ✅ 부품은 품목만 이관, 수량은 `미확인`
- ✅ 미쉐린 외 브랜드는 2주차 화면으로 사장님이 직접 입력

**언제든 하시면 되는 것 (착수 블로커 아님):**
1. ⚪ API 키 스크린샷 정리 — **삭제 권장.** 쓸모는 이미 다 뽑았다 (`04` 2장)

**확인해 주시면 좋음 (없어도 착수 가능):**
3. 매입 할인율이 매입처별로 다른지 여부
4. **폐타이어 처리비** — 서비스 69건에 없음. 받고 계신지·얼마인지
5. **휠밸런스가 "2개당" 요금이 맞는지** (4본이면 2회 청구)
6. **윈터타이어 보관료 150,000원의 단위** (세트당/시즌당/연간)
7. 서비스 단가가 현재 실제 청구액과 같은지 (최종 수정 2024~2025년)
8. MARS 「매입처」 내보내기
9. **부품 매입가·판매가** — 부품 견적을 내려면 필요

**3주차 전까지:**
10. 고객 등급 명칭과 등급별 추가 할인율 (MARS엔 CASH/FLEET뿐 — 우리가 만드는 축)

**2주차 전까지:**
11. 바코드 리더기 준비 (USB 또는 블루투스, HID 키보드 모드 제품)

> ✅ **미쉐린 외 브랜드 재고는 준비물이 아니다.** 2주차 화면이 나온 뒤
> 사장님이 직접 넣으시는 것으로 확정됐다 (D-12 6번). 지금 모으실 필요 없다.

## 6. 후속 로드맵

| 시기 | 범위 |
|---|---|
| 2개월차 | **타이어 보관 관리** — 보관번호 스티커 출력, 랙·열·단 위치, 고객별 목록, 만료·보관료 알림, 환절기 재방문 명단 (**보관료 150,000원 확보 ✅**, 문자 대상 2,593명 확보 ✅) |
| 3개월차 | **작업지시서·정비이력** — 차량별 이력 타임라인 (**공임 마스터는 1주차에 앞당김 ✅**) |
| 4개월차 | **매출·정산** — 일·월 매출, 부가세 자료, 제휴 정산 대조 |
| 이후 | 문자 마케팅, 법인 외상 관리, (선택) MARS 화면 자동화 |

> 유료 차량정보 API는 로드맵에서 **삭제**했다 (D-04 2차 개정).
> MARS 자동 연동도 **삭제**했다 (본사 협의 불가, D-08).
