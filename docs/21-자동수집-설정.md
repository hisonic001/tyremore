# 돈관리 자료 자동 수집 — 설정 안내 (D-41, 2026-11-17)

돈관리 자료를 사장님이 하나하나 올리지 않아도 앱에 들어오게 합니다. 길은 셋입니다.

| 길 | 무엇이 들어오나 | 사장님이 할 일 |
|---|---|---|
| ① 폰 알림 | 신한 SOL Biz **입출금 알림** → 통장에 바로 (속보) | 폰에 알림 전달 앱 한 번 설정 |
| ② 메일 | **홈택스 세금계산서**(보안메일을 사업자번호로 자동으로 엶) · **미쉐린 인보이스** | 구글 스크립트 한 번 붙여넣기 |
| ③ 회계 폴더 | 내려받은 **여신협회·카드사·은행·홈택스 엑셀** | 받은 파일을 `회계\올리기` 폴더에 넣기만 |

> 폰 알림은 「속보」입니다. 나중에 통장 엑셀을 올리면(③) 같은 거래를 **엑셀 내용으로 확정**하고, 줄이 두 번 생기지 않습니다.

---

## 0. 먼저 (Claude 가 합니다 — 사장님 승인 후)

1. 이 작업 갈래(`feat/auto-intake`)를 합치면 1~2분 뒤 매장 앱에 반영됩니다.
2. 받은 편지함 표를 만듭니다: `npx tsx scripts/add-intake.ts`

## 1. 비밀키 · 계좌 이름 넣기 (Vercel 설정 화면)

Vercel → tyremore 프로젝트 → Settings → Environment Variables 에 셋을 넣고 **Redeploy** 합니다.

| 이름 | 값 | 뜻 |
|---|---|---|
| `INTAKE_TOKEN` | 아래 명령으로 만든 긴 글자 | 받는 문의 비밀키. **폰 앱·구글 스크립트에 같은 값**을 넣습니다 |
| `BANK_ALERT_ACCOUNTS` | `1210=신한입금` | 알림 둘째 줄 「입금(**1210**)」의 숫자(계좌 끝 네 자리) → 앱 통장 이름. 「입금」은 SOL Biz 통장 별명입니다. 출금 통장 숫자를 알면 `;5678=신한출금` 처럼 이어 씁니다 |
| `INTAKE_BIZ_NO` | (설정 → 매장 정보에 사업자번호가 있으면 **안 넣어도 됩니다**) | 보안메일 비밀번호 |

비밀키 만들기 (개발 PC, 아무 폴더에서):
```
node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"
```
🔴 이 비밀키는 메신저·메일로 보내지 마세요. 이 키만 있으면 누구나 통장 줄을 넣을 수 있습니다.

## 2. 메일 — 구글 스크립트 (info@psiauto.co.kr 로 로그인한 채로)

1. https://script.google.com → **새 프로젝트**
2. 저장소의 `scripts/apps-script/gmail-intake.gs` 내용을 **통째로 붙여넣기** → 저장
3. 왼쪽 ⚙ **프로젝트 설정** → 맨 아래 **스크립트 속성 추가**
   - `INTAKE_URL` = `https://tyremore.vercel.app/api/intake`
   - `INTAKE_TOKEN` = 1번에서 만든 비밀키
4. 위쪽 함수 고르는 칸에서 **setup** → ▶ 실행 → 「권한 검토」 → 계정 고르기 → 허용
5. 끝. 10분마다 새 메일을 찾아 보냅니다. 보낸 메일에는 **「앱수집」 라벨**이 붙습니다.

- 🔴 **설치한 뒤에 온 메일만** 보냅니다. 지난 메일까지 한꺼번에 보내면 이미 팔린 타이어가 「입고 예정」으로 뜹니다(2026-08-02 사고).
- 보내는 메일과 하는 일:
  | 메일 | 앱에서 |
  |---|---|
  | 홈택스 전자세금계산서 | 사업자번호로 열어 **계산서 장부** |
  | 미쉐린 인보이스 PDF | **입고 대기** |
  | 우리·신한카드 이용대금명세서 | (우리는 사업자번호로 열어) 검산 → 승인 엑셀과 겹치는 줄 빼고 **법인카드 장부** |
  | 팝빌·bill36524 계산서 메일 (금액 있음) | **계산서 장부에 「속보」로 바로** — 홈택스 엑셀을 올리면 같은 줄이 진짜 승인번호로 확정 (2026-11-25) |
  | 스마트빌·이카운트·바로빌 계산서 메일 (금액 없음) | **도착 알림만** — 홈택스 엑셀과 맞춰 빠진 계산서를 알려 줌 |
- 2026-11-17 보강판을 쓰려면 이 파일을 **다시 붙여넣기**만 하면 됩니다(설치 시각 START 는 그대로 남습니다).

### 2-1. 지난 메일 한꺼번에 — 「검토」로 보내기
1. 함수 고르는 칸에서 **backfill** → ▶ 실행. 로그에 「남은 것 없음」이 나올 때까지 여러 번(한 번에 5분까지).
   기본은 2026-07-01 이후 메일 — 바꾸려면 스크립트 속성 `BACKFILL_FROM` (예: `2026/09/01`).
2. 앱은 **해석만** 하고 장부에 넣지 않습니다(「검토」). 보낸 메일엔 「앱수집-과거」 라벨.
3. 개발 PC: `npx tsx scripts/intake-review.ts` → 대조 보고서(`tyremore-data\검증\intake-review-날짜.xlsx`)
   — 카드 명세서 검산·겹침·결제일 통장 출금 / 대행 메일 「확인 필요」 / 홈택스 메일 일치 / 미쉐린 장부 대조.
4. 보고서를 보시고 승인하시면: `--apply 카드` (법인카드 장부) · `--apply 홈택스` (계산서 장부). 미쉐린·대행 메일은 대조만.

## 3. 폰 알림 — MacroDroid (안드로이드)

1. Play 스토어에서 **MacroDroid** 설치
2. **매크로 추가**
   - 트리거: **알림 → 알림 수신** → 앱: **신한 SOL Biz** → 「입출금」 포함
   - 동작: **웹 → HTTP 요청**
     - 방식 `POST`
     - 주소 `https://tyremore.vercel.app/api/intake?key=비밀키`
     - 내용 형식 `text/plain`
     - 내용: `[notification_title]` 줄바꿈 `[notification]`
3. 폰 설정 → 애플리케이션 → MacroDroid → 배터리 → **제한 없음** (꺼지지 않게)
4. 시험: 소액을 입금받거나 알림이 오면, 개발 PC 에서 `npx tsx scripts/intake-status.ts` 로 「반영」이 보이면 성공입니다.

- 접힌 알림(화면에서 잘려 보이는 것)도 앱은 **전체 글자**를 받습니다. 혹시 잘려 들어와도 금액·시각은 들어가고 「잔액 없음」으로 표시됩니다.
- 「계좌표 ○○○○ 를 어느 통장인지 모릅니다」가 보이면 1번의 `BANK_ALERT_ACCOUNTS` 에 그 숫자를 더하세요. 그 사이 알림은 버려지지 않고 보관됩니다.

## 4. 회계 폴더 — PC 수집기

1. 폴더: `OneDrive\바탕 화면\claude\회계\올리기` (수집기가 처음 돌 때 만듭니다)
2. 개발 PC 에서 `npm run collect` (켜 두기) — 또는 작업 스케줄러에 `npm run collect -- --once` (docs/14)
3. 여신협회·카드사·은행·홈택스에서 받은 엑셀을 그 폴더에 **넣기만** 하면 30초 안에 올라가고, 화면 업로드처럼 **자동 대조**까지 돕니다.

- 통장·카드 파일은 **파일 이름에 앱 계정 이름**이 들어 있어야 합니다. 예: `신한 입금계좌 2026Q3.xlsx` → 「신한입금」.
  모르면 올리지 않고 「어느 통장인지 알 수 없습니다」라고 알려 줍니다 — 이름을 고쳐 다시 넣으시면 됩니다.
- 우리카드 「승인 상세내역」과 「이용대금 명세」를 같은 기간에 둘 다 넣으면, 같은 지출이 두 번 잡히므로 **올리지 않습니다**.
- 파일은 옮기거나 지우지 않습니다. 잘못 올라간 것은 화면 「최근 한 일」에서 되돌립니다.

📌 **밀린 3분기 자료**: `회계\3분기\통장거래내역`·`카드매출` 의 파일을 이 폴더에 복사해 넣으시면 됩니다.
