## 5. 규격 파싱 (99.0% 성공)

`상세 항목 및 서비스` 필드가 정형이라 자동 분해가 가능하다.

```
"Michelin    185/60 R 14  82H  TL"
 └브랜드     └폭 └편평비 └림  └하중 └속도  └부가

→ brand=Michelin, width=185, aspect=60, rim=14, load_index=82, speed=H
```

**실패 101건(1.0%)** 은 특수 규격(트럭용 `LT12.5 R 20` 등)이다.
→ 자동 파싱 후 **실패분만 수동 확인하는 화면**을 1주차에 만든다.

> ⚠️ 브랜드에 따라 표기 흔들림이 있다 (`245/45 ZR18`, `235/50R 19`, `255/40   20`).
> 파서는 공백·`Z`·`R` 위치에 관대하게 작성할 것.

## 8. 1주차 작업에 미치는 영향

**줄어든 것**
- 상품 마스터 수작업 구축 → **불필요** (내보내기 + 파싱으로 대체)
- 기표가표 수기 입력 → **불필요**
- 경정비 항목 마스터(3개월차 예정) → **상당 부분 조기 확보**

**새로 필요한 것**
- 규격 파서 + 파싱 실패 101건 수동 보정 화면 (반나절)
- MARS 품번(`번호`)을 보조키로 유지하는 이관 스크립트

**순증감: 1주차 공수 감소.** 오픈 일정 4주는 그대로 유지된다.
