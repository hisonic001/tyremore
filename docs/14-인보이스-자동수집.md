# 인보이스 자동 수집

사장님이 미쉐린·콘티넨탈·금호 사이트에서 **엑셀을 내려받기만 하면**
프로그램이 알아서 읽어 「입고 예정」에 올려 놓습니다.
앱을 열어 파일을 고르고 올리는 절차가 없어집니다.

---

## 쓰는 법

바탕화면에 바로가기를 만들어 두시면 편합니다.

```
C:\dev\tyremore\인보이스-자동수집.cmd     ← 더블클릭
```

창이 하나 뜨고 「지켜보는 중입니다」라고 나오면 됩니다.
**그 창을 켜 둔 채로** 평소처럼 사이트에서 엑셀을 내려받으시면,
30초 안에 알아서 올라갑니다. 끝내실 때는 창을 닫으시면 됩니다.

터미널에서 직접 하실 때는:

| 명령 | 하는 일 |
|---|---|
| `npm run collect` | 지켜보기 (30초마다 확인) |
| `npm run collect -- --once` | 한 번만 훑고 끝 (작업 스케줄러용) |
| `npm run collect -- --catchup` | **지난 인보이스도** 불러오기 |

---

## 🔴 처음 켤 때는 아무것도 올리지 않습니다

다운로드 폴더에는 몇 달 치 인보이스가 쌓여 있습니다.
그것을 다 올리면 **이미 도착해서 팔린 타이어가 「입고 예정」으로** 뜹니다.

그래서 처음 한 번은 지금 있는 파일을 **기록만** 해 두고,
그 뒤에 새로 받는 것부터 올립니다.

지난 것을 일부러 불러오시려면 `--catchup` 을 붙이십시오.

> 실제로 이 일이 있었습니다 — 2026-08-02, 5~7월 인보이스 76건 657본이
> 한꺼번에 「입고 예정」으로 올라갔습니다. 그 뒤에 이 규칙을 넣었습니다.

---

## 사장님 파일은 건드리지 않습니다

다운로드 폴더에는 인보이스가 아닌 파일이 훨씬 많습니다
(보험증권·재무제표·스캔본·제안서…).

- **읽어 보기만 하고 그대로 둡니다.** 옮기지도, 지우지도 않습니다.
- 인보이스가 아니면 조용히 넘어갑니다.
- 무엇을 이미 읽었는지는 따로 기록합니다 (`tyremore-data\collect-state.json`).
  파일 **내용**으로 기억하므로 이름을 바꾸거나 다시 받아도 두 번 올리지 않습니다.

---

## 매일 밤 자동으로 돌리기

Windows 작업 스케줄러에 넣으시면 창을 켜 두지 않아도 됩니다.

```
프로그램:  cmd.exe
인수:      /c "cd /d C:\dev\tyremore && npm run collect -- --once"
```

⚠️ PC가 켜져 있어야 돕니다. 웹서버(Vercel)는 사장님 PC의 다운로드 폴더를 볼 수 없습니다.

---

## 설정 (`.env.local`, 안 하셔도 됩니다)

| 항목 | 기본값 | 뜻 |
|---|---|---|
| `COLLECT_DIRS` | — | 다운로드 폴더 말고 더 볼 곳 (`;` 로 구분) |
| `COLLECT_DAYS` | `21` | 며칠 안에 받은 파일까지 볼지 |
| `COLLECT_STATE` | `..\tyremore-data\collect-state.json` | 읽은 기록을 둘 곳 |

## 아직 안 되는 것 — 사이트에서 **받아 오는** 것까지

지금은 사장님이 **다운로드 버튼을 누르는 것**까지는 하셔야 합니다.
사이트에 로그인해서 파일을 내려받는 것까지 자동으로 하려면
각 사이트의 로그인 화면과 인보이스 목록 화면 구조를 알아야 합니다.

필요한 것:
1. 세 사이트(mymichelin·콘티넨탈·금호)의 로그인·인보이스 화면 구조
2. 아이디/비밀번호를 **사장님 PC 안에만** 두는 방법 (`.env.local`, 웹서버에는 절대 올리지 않음)
3. Playwright (브라우저를 대신 조작하는 도구) 설치

⚠️ 사이트 화면이 바뀌면 멈춥니다. 그때는 다시 맞춰야 합니다.
   반면 지금 방식(폴더 지켜보기)은 사이트가 바뀌어도 멈추지 않습니다.
