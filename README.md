# 타이어모어 업무 자동화

타이어 판매 + 경정비 매장(타이어모어 속초점)의 재고·상담·견적 통합 시스템.
MARS(본사 시스템) + 엑셀 + 수기 장부의 **삼중 입력을 없애는 것**이 목적이다.

프로젝트 맥락·결정 기록은 [`CLAUDE.md`](./CLAUDE.md), 설계 문서는 [`docs/`](./docs) 참조.

---

## 🔴 개인정보 취급 규칙

이 프로젝트는 **고객 실명·휴대폰 2,603건, 차량번호 2,574건**을 다룬다.

| | |
|---|---|
| 저장소에 들어가는 것 | 코드, 설계 문서 |
| **저장소에 넣지 않는 것** | **엑셀 전부, MARS 스크린샷, `.env`** |
| 데이터 위치 | `C:\dev\tyremore-data\` — **저장소 밖** |

- 이 저장소는 **비공개(Private)** 로만 운영한다. 공개 전환 금지.
- `.gitignore`는 2차 방어선이다. **1차 방어선은 데이터를 저장소 밖에 두는 것**이다.
- MARS 「웹 서비스 설정」 화면의 API 키는 **본사 계약 자산**이다.
  값을 코드·문서에 기록하지 않으며, 우리 시스템에서 사용하지 않는다.

## 기술 스택

TypeScript · Next.js 15 (App Router) · PostgreSQL 16 · Drizzle ORM ·
Auth.js · Tailwind + shadcn/ui — 배포는 Vercel + Supabase(서울)

특정 클라우드에 종속되지 않게 설계한다. `docker-compose.yml`로 자체 서버 이관이 가능해야 한다 (D-06).

## 폴더 구조

```
C:\dev\
├── tyremore\          ← 이 저장소 (GitHub 연동)
│   ├── docs\          설계 문서 12종
│   ├── src\           애플리케이션
│   └── CLAUDE.md      프로젝트 기억 · 결정 기록
│
└── tyremore-data\     ← 저장소 밖. 개인정보·엑셀 원본 작업본
```

> OneDrive 폴더에서 옮겨 왔다. `node_modules`(약 4만 개 파일)와 `.git`을
> OneDrive가 동기화하면 빌드가 느려지고 저장소가 손상될 수 있다.
